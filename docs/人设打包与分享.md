# 人设打包与分享（4.1.5 开发版）

## 使用

**仅分享提示词**：点击人设页「仅分享提示词」，只导出自定义补充提示词正文，不包含基础身份和页面设置；正文必须非空。包内 persona.json 严格只有 customPrompt，最多 24000 字符且 UTF-8 JSON 不超过 64 KiB，最低客户端 4.1.0。这个 ZIP 只用于本地分享，不会自动上传或上架。

下面的「打包分享」导出完整设置：

1. 在人设页编辑内容和表达设置，点击「打包分享」。
2. 确认内容，填写包名、作者昵称、包 ID 和版本，选择 ZIP 保存位置。
3. 把 ZIP 发给对方；对方在启动器「聊天 → 人设与回复 → 预设管理」导入。
4. 在人设页的预设列表选择新条目并「应用选中预设」。
5. 导入的人设可直接修改，自动保存到本地副本，不必先复制；原始 ZIP 不变。

自建人设在 `data/personas/user-*.json`，一份人设一个文件。导入的人设同样保存为 `data/personas/` 下的本地预设，修改只写本地副本，不回写原始 ZIP。

本地修改优先于同 ID 的原始数据，重新导入或更新不会覆盖修改；当前不自动合并冲突。需要回到作者版本时，在预设管理里删除本地副本，再重新导入原始 ZIP；操作前请备份需要保留的修改。当前已应用的人设不会立即改变。

`data/persona.json` 仍是兼容旧版的当前运行快照，不是分享文件；不要打包整个 `data/`、`config.json` 或运行快照。

## 分享范围

包含名字、年龄、职业、外观、性格、背景、补充提示词、称呼、角色别名、主动顶嘴、主动延伸话题、主动表达观点、颜文字档位与概率、私聊/群聊字数、讨论上限、历史条数、气泡数。

**不包含**主人账号与昵称名单、联系人、群名单、模型密钥、聊天记录、记忆、服务端口或系统权限。称呼、别名和自由文本仍可能含作者自己写入的私人信息，导出前必须检查；白名单不是隐私自动清洗保证。

## 格式

ZIP 根目录只有 `plugin.json` 和 `persona.json`。清单使用 `Api: 1`、`Kind: "persona"`，最低客户端 `MinAppVersion: "4.1.5"`，无执行能力。ID 为小写字母开头的小写字母、数字和短横线，最多 48 位；更新保持 ID、作者不变，提高版本号。

`persona.json` 是唯一人设数据文件：

```json
{
  "schemaVersion": 1,
  "personaName": "小鱼",
  "age": 23,
  "job": "画家",
  "appearance": "",
  "personality": "沉静，熟悉后会开玩笑",
  "background": "",
  "customPrompt": "",
  "ownerName": "主人",
  "aliases": ["小鱼儿"],
  "masterRoast": true,
  "proactive": false,
  "opinions": true,
  "emoji": "正常",
  "emojiChance": 0.3,
  "privateMaxChars": 140,
  "groupMaxChars": 70,
  "historyTurns": 120,
  "groupHistoryTurns": 100,
  "maxBubbles": 2,
  "discussionMaxChars": 400
}
```

包名是清单 `Name`；角色名是 `personaName`。补充正文最多 24000 字符，人设文件最多 192 KiB，ZIP 最多 1 MiB。实际应用仍需模型输入预算校验。

## 新旧版本双兼容说明

迁移版 4.1.6.1 起，人设页导出的 ZIP 默认包含 `appCompatibility`，同一个包可供旧 4.x 和正式 1.x 使用。纯提示词的旧代最低版本为 4.1.0，完整设置为 4.1.5；正式代最低为 1.0.0。顶层 MinAppVersion 仍保留旧代最低版本，供不认识新字段的已发布客户端读取。

原来没有兼容字段的旧包不会自动视为正式代兼容，可由作者重新导出或明确声明两代范围。导入时以包内声明为准。
